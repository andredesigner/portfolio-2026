# Design Tokens

- `--color-ink`: `46 46 46` / `#2E2E2E`
- `--color-paper`: `255 255 255` / `#FFFFFF`
- `--color-accent`: `51 102 255` / `#3366FF`
- `--color-line`: `46 46 46` / `#2E2E2E`

## Typography
- família principal: `Articulat CF`, fallback `Inter`, `system-ui`
- Label: 14px / 22px / 600 / uppercase
- Text: 16px / 24px / 400
- Text big: 20px / 28px / 500
- H1: 56px / 68px / 500 / uppercase
- H2: 44px / 1.16 / 500
- H3: 36px / 1.16 / 500

## Radius
- pills e botões redondos: 999px
- evitar cards arredondados no layout editorial principal

## Spacing
- margem desktop: 48px
- gap desktop: 32px
- margem mobile: 20px
- gap mobile: 20px

## Grid
- desktop: 6 colunas
- mobile: 1 coluna
- conteúdo principal frequentemente começa na coluna 3
