## Princípios Visuais

### Minimalismo editorial
A interface deve evitar excesso de elementos.

### Tipografia dominante
A tipografia é um elemento estrutural da composição.

### Respiro visual
Grandes áreas negativas devem existir para criar ritmo.

### Contraste entre seções
Alternar:
- claro/escuro
- denso/leve
- técnico/editorial

### Composição assimétrica
Evitar layouts excessivamente centralizados.


## Tipografia

A tipografia deve:

- criar impacto
- estruturar ritmo
- parecer editorial
- dominar a composição

### Regras

- títulos grandes
- excelente line-height
- espaçamento refinado
- pouco uso de peso extremo
- evitar excesso de variações tipográficas

### Sensação desejada

- elegante
- técnica
- contemporânea
- premium

## Grid e Composição

### Grid

- grids amplos
- alinhamentos consistentes
- margens generosas

### Composição

A composição deve:
- alternar densidade
- criar ritmo visual
- evitar repetição previsível

### Imagens

As imagens devem:
- funcionar como blocos editoriais
- ocupar espaço com intenção
- criar impacto visual

# Motion System

### Sensação

O motion deve parecer:
- suave
- físico
- elegante
- conectado ao scroll

### Evitar

- bounce
- elastic
- exageros
- efeitos chamativos
- transições rápidas demais

### Referências

- Apple
- Heights
- Linear

### Scroll

As animações devem:
- acompanhar o scroll
- utilizar scrub quando necessário
- evitar flickering
- evitar opacity excessiva

### Transições

As trocas de página devem:
- ser suaves
- discretas
- refinadas

## Sistema de Cores

### Objetivo

Criar contraste sofisticado.

### Regras

- utilizar como base: #2E2E2E, #FFFFFF, #3366FF
- #FAFF33 e #009C58 ficam reservadas para assets de bandeira/experimentos, não para a UI principal
- uso estratégico do contraste
- evitar excesso de saturação
- evitar gradientes clichês

### Sensação

- elegante
- moderna
- precisa

## Componentes

### Componentes globais

- Header
- Footer
- CTA
- Project Row
- Buttons
- Wordmark
- Brand Symbol

### Layout Figma 2026

- largura base: 1440px
- margem lateral: 48px
- grid: 6 colunas
- gap: 32px
- header sticky com 208px de altura no desktop
- títulos principais: 56px / 68px, uppercase
- cards de projeto: bloco textual sem imagem, metadados à esquerda e título azul à direita
- footer: CTA, Linkedin, Currículo, E-mail, copyright, botão Subir, wordmark grande e símbolo vertical

### Componentes editoriais

- Fullscreen Media
- Statement
- Text Block
- Metrics

### Componentes de motion

- Sticky Projects
- Page Transition
- Scroll Reveal

## O Que Evitar

Não utilizar:

- visual startup genérico
- excesso de cards
- sombras exageradas
- glassmorphism
- gradientes clichês
- excesso de animações
- UI carregada
- excesso de centralização
- layouts previsíveis
- spacing inconsistente
- componentes excessivamente decorativos
- design sem técnica
